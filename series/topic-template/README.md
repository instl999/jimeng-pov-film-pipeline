## 怎么开工

全部步骤在仓库根目录的 `AGENTS.md` 里。命令都在仓库根目录下跑，片子放在 `films/<片名>/`：

1. `python3 series/tools/film.py intake <粗稿> films/<片名>`　生成 `film.json` 骨架和 `DECISIONS.md`。
2. 读稿，填好 `DECISIONS.md`，把片子写进 `film.json`（形状见同目录的 `film.skeleton.json`，每个键的意思见 `series/FILM.md`；每个镜头自己的文字不少于 3,000 字）。
3. `film.py check` 和 `film.py budget` 都过了，把 `DECISIONS.md`、`shots/E01.md` 和 `cast/` 下的图片提示词一起发给片主。**第一次停：片主没点头之前，什么都不生成。**
4. 片主点头后，把原话记下来：`film.py approve films/<片名> "原话"`。然后 `images --run` → `preview`（可选）→ `draft --run` → 逐条看片、`review` → `compose`。**第二次停：片主看成片。**
5. 片主说没问题：`film.json` 里写 `"accepted": true`，`compose --final`；写 `cover/E01.md`，`cover --run` 出图、选图、压标题。

用哪个引擎出片在 `film.json` 的 `"engine"` 里选：`jimeng`（默认，Seedance 2.5，花积分）或 `h3`（MiniMax H3，租显卡按分钟计费，每个镜头的文字不少于 8,000 字）。
