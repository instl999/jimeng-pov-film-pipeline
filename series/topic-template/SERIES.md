## 2. 每集的骨架（顺序可以微调，一个都不能少）

| 拍点 | 要求 | 本系列的写法 |
|---|---|---|
| 钩子 | 前 3 秒：主人公的手正在做那件回不了头的事，旁边已经有人在反应。片头字从第一帧就在 | <<例：手把存折拍在柜台上，柜员抬眼>> |
| 当众被笑 | 身边的人当面、说出口地看不起他，至少一个人、一句能记住的话 | <<例：「这不就是游戏币吗」>> |
| 押注 | 一个看得见的动作：签字、按下去、把钱推过去。他只说一两个字 | |
| 时间跳 | 日期行换年份；手和袖口跟着变（年代、境况） | |
| 兑现 | 看得见的结果，不是嘴上说的：人站在车前半天说不出话、钥匙交到手里 | |
| 回头来求 | 当初笑他的同一个人回来，姿态反过来（站着的坐下、仰着的弯腰） | |
| 回声 | 开头的一句话或一件东西，结尾换个样子回来 | |

## 3. 主人公

- 每集是不是同一个"我"：<<每集各自 / 同一个人>>
- 声音（每集一字不改）：<<三十岁男声，低平，慢，像自言自语>>
- 他话很少：别人冲他说，他回一两个字或者用手回答。台词不到全片三分之一。
- 他从不解释自己怎么知道后来的事；片头字已经说了"假如回到……"。

## 4. 时代和观感

- 全系列统一的观感一句（写进 series.json 的 look）：<<媒介、胶片、颗粒、镜头>>
- 每个年代各自的调子写在每集的 styles 里：艰难的年代冷、灰、蓝；兑现的场面和活人的地方暖。
- 每个年代两三件真实的年代物件；不出现可读的字、品牌标志。

## 5. 数字

- 屏幕上的钱数、价格、倍数（片头、日期行、旁白）都要有出处，写进 film.json 的 facts。真实历史价格写清楚来源和日期；故事里的身家写清楚怎么算出来的。
- 人物嘴里说的数字是台词，不用出处，但别和屏幕上的数打架。

## 6. 不出现的东西

- 真实公众人物的名字和长相（换成描述，比如「那个做聊天软件的」）。
- 画面里的品牌和可读文字。台词里提到品牌照说。
- 彩票、赌球、押注这类：平台敏感，每一处在决策单里单独定怎么拍。
- 画外音、内心独白、音乐。
